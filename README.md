#                         | Rename Batch |

Утилита для массового переименования файлов с автоматической нумерацией.

## Возможности
- Массовое переименование файлов с номерами
- Предпросмотр перед переименованием
- Отмена последней операции
- Современный GUI на CustomTkinter

## Установка
pip install -r requirements.txt
python assets/main.py ( либо запустите уже готовый .exe файл)
